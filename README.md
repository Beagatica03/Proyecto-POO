Sistema de Gestión de Empleados
Descripción
Proyecto desarrollado para la asignatura TI3021 Programación Orientada a Objetos Seguro.

La aplicación implementa un sistema de gestión de empleados y proyectos basado en un diagrama UML, aplicando los principios fundamentales de la Programación Orientada a Objetos:

Abstracción
Encapsulamiento
Herencia
Polimorfismo
Asociaciones entre clases
Funcionalidades
Gestión de empleados
Gestión de departamentos
Gestión de proyectos
Asignación de empleados a proyectos
Registro de horas trabajadas
Generación de informes
Gestión de usuarios, roles y permisos
Auditoría de acciones del sistema
Validación y sanitización de datos
Cifrado y generación de hashes
